Formulation Mathématique de la Prédiction SVD

Pour un utilisateur $u$ et un film $i$, la note prédite $\hat{r}_{u,i}$ est modélisée par :

$$\hat{r}_{u,i} = \mu + b_u + b_i + q_i^T p_u$$
  • $\mu$ : moyenne globale de toutes les notes dans le dataset (3.50).
  • $b_u$ : biais individuel de l'utilisateur (spectateur généreux ou sévère).
  • $b_i$ : biais individuel du film (blockbuster apprécié ou nanar boudé).
  • $p_u, q_i \in \mathbb{R}^{50}$ : vecteurs de facteurs latents capturant les goûts thématiques profonds.
